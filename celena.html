Project Overview

During the final 2 weeks, I developed my own enhanced version of Spear Fisher with unique features and improvements. This page showcases my individual contributions and innovations to the base game.

My Key Enhancements

Player Ranking System

Creation of a player ranking based on their score, with a panel allowing players to enter their name and a panel displaying the final ranking at the end of the game.

Weapon Selection

Option to select your weapon with a choice between two weapons: harpoon or trident.

Dynamic Music

Addition of dynamic music at the start of a fishing game to enhance immersion and player experience.

UI Improvements

Comprehensive improvement of the game's 2D interface for better usability and visual appeal.

Code Example 1: Player Ranking System

function addScore(name, score) {
  let scores = loadLeaderboard();

  scores.push({ name: name, score: score });

  scores.sort(function (a, b) {
    return b.score - a.score;
  });

  scores = scores.slice(0, 10);

  saveLeaderboard(scores);
}

Code Example 2: Weapon Selection System

function saveWeapon(weapon) {
  localStorage.setItem('weapon', weapon);
}

function loadWeapon() {
  return localStorage.getItem('weapon') || 'spear';
}
