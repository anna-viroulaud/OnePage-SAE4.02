Project Overview

During the final 2 weeks, I developed my own enhanced version of Spear Fisher with unique features and improvements, focusing on an immersive treasure hunting adventure in a marine XR universe. This page showcases my individual contributions and innovations to the base game, including advanced physics, space management, collision detection, and full interaction between real and virtual elements.

My Key Enhancements

Landing Page

Interactive landing page for experience initialization with marine themed immersion before entering the treasure hunting adventure.

Space Management

Advanced system for managing real-world space and mapping it to the virtual environment.

History Management

Complete tracking system for player actions, and the best sessions performed by the player in the game.

Spawn System

Dynamic fish spawning system that generates fish from real windows in the room, creating seamless integration between physical and virtual spaces.

Harpoon-Space Physics

Advanced physics for harpoon projectiles interacting with real-world boundaries and virtual space.

Marine Universe

Complete the aesthetics of the underwater world with corals, rocks and flowers, as well as ambient sounds creating a total immersion in the ocean.

Weapon Selection

An Option Panel to select the weapon you want, a treasure chest like an easter egg, with four different weapons.

Dynamic Music

Adaptive background music that changes based on player actions, underwater environment, and treasure hunting progress, enhancing immersion.

Code Example 1: Add score to leaderboard

function addScore(name, score) {
  const scores = JSON.parse(localStorage.getItem('leaderboard') || '[]');
  scores.push({ name, score });
  scores.sort((a, b) => b.score - a.score);
  localStorage.setItem('leaderboard', JSON.stringify(scores.slice(0, 10)));
}

Code Example 2: Simple fish spawner

function spawnFish(intervalMs = 2000) {
  setInterval(() => {
    const fish = document.createElement('a-entity');
    fish.className = 'fish';
    document.querySelector('a-scene')?.appendChild(fish);
  }, intervalMs);
}
